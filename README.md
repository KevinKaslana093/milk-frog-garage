## 怎么玩

每关先运镜观察地图、终点和星星，再回到空白工坊。先放入奶蛋奶豆双人舱，再自由搭车；也能先摆零件。没有预装车，没有自动填入解法。存档蓝图仅在玩家点「载入」时读取。

到达终点即可过关，三星是可选收藏，可以分次通关补齐。二十关共60颗星。每关限定零件库存，依次解锁；已有前五关收藏和解锁记录保留。

| 操作 | 电脑 | 手机 |
|---|---|---|
| 放置零件 | 点击零件再点格子，或拖放 | 点击零件再点格子 |
| 旋转风扇/火箭 | R 或旋转按钮 | 旋转按钮 |
| 轮式动力 | A/D、左右箭头；发动机按钮持续向右 | 长按左右，或点发动机 |
| 刹车 | B / 下箭头 | 长按刹车 |
| 风扇独立开关 | F/G/H 或 1/2/3 | 对应车上编号的风扇按钮 |
| 火箭 | 按住空格，有限燃料 | 按住点火 |

手机锁定竖屏时，整个画面侧转90°，不依赖浏览器强制横屏权限。电脑保持正常布局，可全屏。切后台自动暂停并清除输入。

## 这次的物理改动

- 风扇与火箭的喷气方向和推力相反。绿色箭头表示车的推力，白色气流/火焰在另一侧；拼装时显示四向说明。推力跟随零件朝向和车身旋转，在安装位置施力，偏心会扭转车身。
- 发动机通过轮轴传动，自身没有水平推力。没有发动机时轮式驱动按钮不可用，按方向键也不会给车加力。重力溜坡和惯性滑行正常保留。风扇作为自带动力的独立零件使用。
- 放气改为一次性逐只放掉气球，松手不会重新充气。按钮显示剩余数量，与驾驶区分开放大；重试恢复原设计。
- 碰撞强度来自接触法线方向的速度（包含转动），轻碰不扣耐久，中等冲击产生裂纹，强冲击拆掉相应部件。失去与双人舱连接的木框、部件和轮子也会脱落。
- 脱落部件是独立碰撞刚体，继承断裂时的速度。车体重新计算质量/重心、轮轴重新连接；掉发动机或轮子会失去相应传动，掉风扇会失去该推力。车坏了仍可带两人一起到终点。
- 120 Hz 固定物理步长。驾驶只施加力/扭矩；断裂时设置新碎片速度用于继承动量，不是用坐标或速度脚本推车。

## 开发与验证

不需要安装依赖；物理库和图片随包提供。Node.js 18+：

```sh
npm test
npm run build
```

62项自动测试包含二十关实际受力通关、60颗星可达、重力/无动力对照、四向推力、偏心力矩、碰撞断裂、断裂动量、动力失效、气球逐只释放、重试及存档。浏览器验证和设备边界见 TESTING.md。

`data/levels.json` 是关卡数据，`src/physics.js` 是浏览器与测试共用物理实现。数据中的 `example` 及 `scripts/solution_controls.js` 是验证解法，不会自动装配或驾驶玩家车辆。构建生成 dist 与上级目录的单文件离线版。主分支推送后 GitHub Actions 先测试、再部署 Pages；生产文件带版本号避免混用缓存。

## V0.4.1 独立风扇控制

每个已安装风扇有自己的编号、颜色和开关按钮，显示方向、开关状态和快捷键。F/1控制1号，G/2控制2号，H/3控制3号，可任意组合启动。车上和拼装预览标有相同编号。没有风扇时不显示风扇按钮；脱落的按钮禁用，其余编号不变。暂停保留开关状态，原样重试会全部关闭。编号按当前蓝图的安装顺序生成，修改/拆除后出发前可在预览确认。
