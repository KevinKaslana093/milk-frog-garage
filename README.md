## 玩法

每关先展示地图全貌，镜头带过终点、星星和地形，再回到起点组装。可跳过、重新观察，也可随时查看全图。开场运镜约 6.3 秒；开启系统减少动态效果时变为短暂静态全图。

每一关都从完全空白的20格组装区开始，没有预装车辆。先从零件栏选奶蛋和奶豆，再点击网格放入2×2双人舱；也可以先摆零件再放双人舱。选底部零件后点格子，桌面也能拖放。再次点已装零件可拆除，同类风扇/火箭再点可旋转。双人舱可移动，或选择“拆除”收回零件栏。连接、重叠、库存、轮轴都有检查，出发前显示具体问题。

已移除“示例车”功能。“清空”收回所有零件与双人舱，可撤销。未完成的设计也能按关卡保存、载入；进入新关卡不会自动载入旧车。修改载具、原样重试保留玩家自己的设计。撤销/重做最多保留60步。

- A / D 或左右箭头：按住驱动车轮。
- “发动机”：一键开关自动前进；刹车和后退优先。
- B / 下箭头：刹车。
- F：开关风扇。
- 空格：按住点火，火箭燃料有限。
- V：按住放气减弱气球浮力，松开恢复。
- Esc：暂停/继续。切后台自动暂停，释放输入；需手动继续。
- R：旋转零件；Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y：撤销 / 重做；M：查看全图。
- 电脑右上角“全屏”可进入/退出全屏；鼠标拖放和键盘驱动都可用。
- 手机：整个画面侧转90°，点击或长按对应按钮，支持多指组合操作。无需点击横屏提示，也不调用强制锁屏接口。

**奶蛋、奶豆始终在同一个 2×2 驾驶舱。翻车不自动失败；两人随舱完整进入终点区域即可过关，零星也能过关。** 每关有三颗实际星星；通关时把本次拾取的星星与既有收藏合并，不要求一趟全拿。失败不会写入本次收藏。浏览器本地保存解锁和收藏，清除浏览器数据会丢失记录。

## 五关与路线参考

| 关卡 | 地形问题 | 造车思路 / 收藏路线 |
|---|---|---|
| 风车谷 | 下坡蓄势、谷底、反坡、小屋终点 | 自行拼好木框、车轮、发动机与双人舱后，长按前进或开发动机，可拿三颗星 |
| 蘑菇岭 | 三层回折山路、两次下落、双向驾驶 | 上层向右，中层向左，下层再向右到终点；三层各一颗星。双发动机配稳定车架已实测可行 |
| 断桥溪 | 断崖跳台、独立桥台、谷底补救路 | 开风扇+发动机走上路拿第1、3星；关闭风扇走谷底补第2星，再到终点。两次通关合并三星 |
| 云朵峡 | 气球减重、空中穿越、右岸落点 | 自行拼装后开风扇+发动机；避免过早放气，可拿三颗星。不同装配需自己调整浮力 |
| 落日矿谷 | 下坡、发射斜面、矿谷、终点山脊 | 自行拼装后前进；接近点火路牌（距终点约140米）短按点火约0.4秒，再继续前进 |

## 实现与边界

- 本地 Matter.js 0.20.0；120 Hz 固定物理步长，每帧最多追赶10步。
- 连通车身为复合刚体，轮子为独立刚体与旋转轴约束，同车禁用自碰撞。
- 驱动用扭矩及反作用扭矩，推力在零件安装点施加；不直接修改车辆坐标/速度来行驶。
- 所有坡面顶点与碰撞几何一致。独立桥台有真正下方空间。
- 终点检查双人舱的所有顶点和乘员标记，车头或轮子单独到达不会获胜。
- 两个角色独立进行受加速度驱动的轻微晃动。无角色抛飞、零件断裂、联机双人操控。
- “双人”指奶蛋、奶豆两位主角同乘一车，不是两名玩家的网络联机。
- 角色采用用户两张参考图的背景提取衍生 PNG，不是先前的简笔替代形象；仍非逐像素无损抠图或完整多角度动画资产。对应已确认：无蝴蝶结=奶蛋，蝴蝶结=奶豆。
- 音效为原创合成短音；没有背景音乐。人物、零件和场景仍可继续精修。
- 手机操作已通过 Chromium 触屏模拟测试，**未做真实安卓/iOS设备或低端机测试**。
- 本阶段是可玩的网页迭代版，不是微信小游戏发布包，不宣称通过微信审核。

## 源码与复测

无安装依赖步骤；Node.js 18+ 用于测试/打包，直接游玩不需要 Node。

```sh
npm test
npm run build
```

- `src/physics.js`：蓝图校验与真实物理，同一实现同时供浏览器和自动测试使用。
- `src/game.js`：继承并改进原型状态机、编辑器、输入、运镜、收藏与存档。
- `src/art.js`：原创场景/零件绘制，角色 PNG 渲染，地形缓存。
- `data/*.json`：全部五关、三颗星、库存、物理参数、可通关示例车。
- `scripts/test_physics.js`：物理、通关、两路线、星星可达性、输入前提、蓝图与重启测试。
- `test-results/physics.json`：实际测试结果及每关示例蓝图。
- `TESTING.md`：浏览器验收、已修问题与测试边界。
- `assets/ASSETS.md`：角色参考对应、生成方式与提示词记录。
- `vendor/LICENSE-Matter.txt`：Matter.js MIT 许可证。

`npm run build` 同步 JSON 到 `src/data.js`，生成 `dist/` 和上级目录的独立离线 HTML。原交接的 `scripts/sync_data.py` 仍可单独使用。

## GitHub 自动发布

主分支每次推送后，GitHub Actions 会先运行31项物理检查，成功后打包并部署 `dist/` 到 Pages。源码仓库与可玩的网页入口分开。发布流程遵循 [GitHub Pages 官方工作流文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

V0.3.3 采用 CSS 侧转整个游戏容器，渲染仍用旋转前的布局尺寸，按钮点击交由浏览器处理变换。这样不依赖受浏览器支持限制的 [Screen Orientation lock](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)。本机已验证模拟锁定竖屏，不等同于微信实机验证。

## V0.3.4 变更

五关统一空白开局，双人舱由玩家手动放置。第二关改为三层回折路线。旧第二关的星星收藏会单独重置，其他关卡收藏、解锁与保存蓝图不变；旧蓝图仍需手动点击载入。数据里的 `example` 与 `starter_blueprint.json` 只供开发测试验证可解性，游戏开局不会使用它们。
